# NeoBliz1's Old-School Profile Page

This project is a personal portfolio website designed with a retro, "old-school" aesthetic. It showcases my skills and projects in a unique and interactive way.

## Features

*   **Responsive Design:** The layout adapts to different screen sizes using modern CSS like Flexbox and Grid.
*   **Dark Mode:** Toggle between a light and dark theme for comfortable viewing.
*   **Interactive Skills Meter:** A dynamic and animated skills section to visualize my proficiency in various technologies.
*   **Project Showcase:** A gallery of my work with links to live demos and source code.
*   **Contact Form:** A functional contact form with reCAPTCHA v2 integration.
*   **Internationalization (i18n):** Supports multiple languages.

## Technology Stack

This project is built with a combination of front-end technologies:

*   **HTML5:** For the structure and content of the website.
*   **CSS3:** For styling, layout, and animations.
*   **JavaScript (ES6+):** For interactivity and dynamic features.
*   **jQuery:** Used for DOM manipulation and its rich ecosystem of plugins.
*   **p5.js:** For creative coding and animations.
*   **simpleParallax.js:** To add parallax effects to images.
*   **ScrollMagic.js:** For scroll-based animations.
*   **Modernizr:** To detect browser features.
*   **Font Awesome:** For icons.
*   **Google Fonts:** For custom typography.

## How to Run

1.  Clone the repository: `git clone https://github.com/NeoBliz1/neobliz1.github.io.git`
2.  Open the `index.html` file in your web browser.
